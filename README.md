# Retail Transaction Data Cleaning & Power BI Dashboard

## Project Overview
This project focuses on cleaning, validating and analyzing retail transaction data to generate meaningful business insights using Python, Pandas and Power BI.

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook
- Power BI

## Project Workflow
1. Loaded and explored the retail transaction dataset using Pandas.
2. Identified missing values, duplicate records and invalid data.
3. Handled missing Discount Name values by replacing them with "No Discount" based on the dataset's discount information.
4. Identified and handled invalid negative Net Amount records.
5. Converted purchase timestamps into datetime format and preserved transaction and customer IDs as text.
6. Validated the cleaned dataset.
7. Created interactive Power BI dashboards for business analysis.

## Data Cleaning & Validation
- Handled 27,585 missing Discount Name values.
- Identified and handled invalid negative Net Amount records.
- Checked missing values and duplicate records.
- Corrected relevant data types.
- Validated the cleaned dataset for consistency.

## Power BI Dashboard
The dashboard contains two pages:
- **Executive Overview:** Provides an overview of retail sales performance.
- **Customer & Discount Analysis:** Helps explore customer purchasing behaviour and discount-related patterns.
